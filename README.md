# house33: Ροδοδάφνης 13 renovation

Drawings, photos, the kitchen design and an interactive 3D model for the apartment renovation.

- **3D model:** open `model/rododafnis-13-3d.html` in a browser (it needs internet to load three.js). Live version: https://claude.ai/artifact/PWmBXquccZQUBg6Pud3SBQ
- **Notes:** `docs/project-notes.md` has the room areas, measured dimensions, kitchen spec, plumbing and electrical details, the conflicts between drawings and the assumptions in the model.
- **Source files:** `source/` (drawings, kitchen, photos before and during demolition, target render).
- **Tools:** `tools/extract_walls.py` measures the walls from the plumbing PDF.
